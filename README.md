# Dashboard_ThePower
Dashboard depresión estudiantil

📊 Análisis de la Depresión Estudiantil

📖 Descripción
Este proyecto analiza la relación de la depresión estudiantil entre diversos factores directamente involucrados. Se han estudiado variables como el género, la franja de edad, los hábitos alimentarios y la duración del sueño, entre otras. El objetivo es identificar patrones y correlaciones que puedan ayudar a comprender mejor este problema y sus posibles causas.

📂 Estructura del Proyecto
├── data/               # Datos crudos y procesados
├── notebooks/          # Análisis y visualización en tablas dinámicas y gráficos
├── src/               # Scripts de procesamiento de datos
├── results/           # Gráficos y mapas generados
├── README.md          # Descripción del proyecto

pandas

pip install -r requirements.txt

📊 Resultados y Conclusiones
Se han analizado los datos mediante tablas dinámicas y gráficos para encontrar relaciones entre la depresión y variables como:

Género: Diferencias en la prevalencia de depresión entre hombres y mujeres. (Hay un 11,6 más de hombres padeciendola que mujeres)
Franja de edad: Identificación de grupos de mayor riesgo. (De los 18 a los 24 se comprimen las edades con más afectadas)
Hábitos alimentarios: Posible impacto en la salud mental. (Se comprueba que unos hábitos poco saludables contribuyen a un augmento de la depresión)
Duración del sueño: Relación entre horas de descanso y presencia de depresión. (Los estudiantes que tienen una media inferior a las 5 horas de sueño, tienen más depresión)
Ubicación geográfica: Distribución de los casos según ciudad. (Las ciudades de la India son las que registran un mayor número de alumnos con depresión)
Se han generado gráficos explicativos y mapas de distribución para visualizar mejor los patrones detectados.
